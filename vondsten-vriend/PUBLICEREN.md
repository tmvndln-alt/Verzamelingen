# Voor jou (eigenaar): de app online zetten

De app is een gewone website zonder server. Je hebt alleen een plek nodig om hem neer te zetten, zodat je vriend een link kan openen.

1. Zorg dat de map `vondsten-vriend` in de hoofdbranch (`main`) van de repo staat.
2. Ga op GitHub naar de repo, dan **Settings**, dan **Pages**.
3. Kies bij Source: **Deploy from a branch**, branch **main**, map **/ (root)**. Tik Save.
4. Na ongeveer een minuut staat de app op `https://<jouw-gebruikersnaam>.github.io/Verzamelingen/vondsten-vriend/`.
5. Stuur je vriend die link plus het bestand `HANDLEIDING.md` (de handleiding zit ook in de app onder Hulp).

Let op: GitHub Pages is openbaar voor wie de link kent. In de app staan geen gegevens en geen sleutels; alles staat op de telefoon van je vriend.
Alternatief zonder GitHub: de map werkt ook op elke andere gewone webhost, zolang de link met https begint.
